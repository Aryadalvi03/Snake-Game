# 🐍 Snake Game

This is a classic Snake Game developed using Java and Java Swing. The game allows the player to control a snake using keyboard inputs and collect food to increase the score. Each time the snake eats food, its length increases, making the game progressively more challenging.

The game ends when the snake collides with the wall or with itself. This project demonstrates core Java concepts such as object-oriented programming, event handling, GUI development, and game logic implementation.

## Features

- Smooth keyboard-controlled movement  
- Real-time score tracking  
- Random food generation  
- Collision detection  
- Game over logic  

## Technologies Used

- Java  
- Java Swing  
- AWT  
- Object-Oriented Programming (OOP)  

## How to Run

Clone the repository, open the project in any Java IDE or VS Code, compile the main Java file, and run the program to start playing the game.
